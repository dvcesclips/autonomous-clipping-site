# Autonomous Clipping public site

A self-contained public website for Autonomous Clipping's TikTok app configuration and review.

## Files

- `index.html` — public landing page and authorized short-form workflow overview
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `styles.css` — responsive, dependency-free styles

## Local preview

Open `index.html` in any modern browser. No build step, JavaScript, external assets, trackers, or dependencies are required.

## GitHub Pages

Publish this repository from the desired branch and the site root in the GitHub Pages settings. The root `index.html` is the entry point.
